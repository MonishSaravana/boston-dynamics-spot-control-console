# SCOPE interface direction

## Brief

User-supplied brief: unify the existing local consoles into Operate, Runs,
Maps and Evaluate. This is a desktop engineering tool for a supervised
operator. Confirm evidence, preview a world-frame destination, explicitly
GO, and keep Stop in reach. Preserve all existing control and perception
capabilities. M5 remains READY FOR PHYSICAL VALIDATION.

The supplied screenshots guide hierarchy, density and dark materials; they
are not evidence of implemented features. No generated imagery or new
models. No paid image generation. No research milestone.

## Current and keep list

speed (0.05–0.35 m/s), requested height (0–10 cm), roll/pitch (±5°),
gesture mode, five fisheye views, split view, approximate front panorama,

## Tokens and shell

Ground #0d1011; surface #141819; raised #1b2122; border #303a3c; text
#eef3f1; secondary #acb7b8. Mint #9aebd2 carries selection/approval, amber
#edc76e denotes uncertain target evidence, red #c83743 denotes Stop or
failure. Dark-only operator surface; no unrequested light-mode toggle.

Arial/Helvetica-compatible grotesque for broad installed availability and
compact controls; native system fallback for absent fonts. No runtime font
network request. Numerals tabular. Mono only for copied commands and raw
telemetry. Scale 12, 13, 14, 16, 20, 24 px. Spacing 4, 8, 12, 16, 24, 32.
Control radius 5 px, panel radius 8 px, circular direction controls.

Four-item top navigation. Operate: camera and route on the left, target
workflow on the right, manual controls below. Maps: spatial canvas with
layers, entity inspector and advanced Rerun access. Runs: local artifact
index and read-only inspection. Evaluate: existing commands, result files
and module controls. Desktop at 1280×720 and 1920×1080 first; small screens
retain evidence and all actions with vertical scrolling. Stop stays sticky.

## Content and states

Header: SCOPE / Operate / Runs / Maps / Evaluate / OFFLINE DEMO or LIVE /
STOP MOVEMENT / Zero-velocity request · class E-stop separate.
Connection: local connection status / Connect to Spot / Try offline demo.
Mode: Observe (sensors only; GO disabled), Dry run (GO records the exact
SE2 destination; no physical command), Robot control (lease and fresh
readiness required; confirmation and GO separate). Demo GO is virtual.
Camera: Selected evidence / view selector / Camera & perception settings /
Synthetic room · not Spot footage, or measured Spot source and frame age.
Target: Object query / Find target / Use pointing (Simulate pointing in
demo) / candidates / entity label / world frame / center in m / evidence
age in s / score, uncalibrated / source / CONFIRM TARGET / Reject.
Destination: x/y in m / heading in degrees / standoff in m / clearance in m /
observed-free route samples / Preview again / GO · virtual, GO · dry run,
or GO · robot. View faces target; camera does not restrict world direction.
Manual: Power On / Stand / speed range / hold W/A/S/D or arrows / requested
posture sliders / Apply requested standing posture / supervised gesture /
measured model availability. Demo manual requests stay disabled.
Settings: acquire / display / Hz per source; one processing visual/depth
pair; alignment verified physically, never assumed; module enabled and Hz.
Empty: connect or demo to see frames; no runs discovered; no target selected.
Pending: reading sources, query pending, map awaiting verified depth.
Error: retained query, explicit error and retry. Disabled: reason beside
control. Stale: target/robot ages; confirmation and GO unavailable. Stop:
clear authorization, pending controls and held inputs. All state comes
from existing adapters, with cached snapshots and worker-owned processing.

## Signature and performance

Confirmation transfers the highlighted camera evidence to a map destination
and facing arrow. On preview, a brief 180 ms opacity transition clarifies
the new route; reduced motion is instant. Actual robot pose updates only
from measured state (or the labeled virtual demo). No ambient animation,
WebGL engine or decoration in the command path. Browser polls throttled
snapshots, backend sensors/perception/rendering use a worker, Stop bypasses
that worker. Rerun remains the advanced 3D/timeline implementation.

Voice: brief, exact about evidence, units and movement authorization.
